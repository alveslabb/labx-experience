# 🧪 LabX Experience

O LabX Experience é um sistema desenvolvido para organizar e incentivar o uso dos laboratórios escolares de Física, Química e Biologia, permitindo agendamentos, registro de atividades, ranking de turmas e acompanhamento do desempenho dos alunos de forma prática e interativa.
O projeto busca facilitar o gerenciamento do laboratório através de agendamentos, controle de atividades, ranking de turmas e acompanhamento do uso do ambiente escolar.

## 📚 Objetivo

O principal objetivo do projeto é:

- Incentivar o uso frequente dos laboratórios
- Melhorar o aprendizado prático dos alunos
- Organizar os horários de utilização
- Registrar atividades realizadas

## 🎯 Motivação do Projeto

O projeto surgiu a partir da observação de que os laboratórios escolares eram pouco utilizados, mesmo sendo ambientes importantes para o aprendizado prático.

Com isso, o LabX Experience foi criado para tornar as aulas mais dinâmicas, organizadas e interessantes para os alunos.
