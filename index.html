Sobre o LabX

O LabX Experience é um sistema desenvolvido para facilitar o gerenciamento dos laboratórios dentro das escolas.

A plataforma permite organizar os horários, acompanhar as aulas agendadas e facilitar o acesso aos laboratórios para alunos e professores.
